# 304 字幕编辑工作台

## 1. 功能目标

让用户围绕“文本、入点、出点”高效完成字幕微调。

## 2. 主要场景

- 修改识别文本
- 调整某句字幕出现和消失时间
- 补一条漏掉的字幕
- 合并两条过碎的字幕
- 将一条过长字幕按指定文字位置分成两条
- 一边播放一边校时间

## 3. 功能范围

包含：

- 字幕列表浏览
- 当前字幕高亮
- 文本编辑
- 入点编辑
- 出点编辑
- 插入前一条 / 后一条
- 合并下一条
- 手动分割当前字幕
- 音频播放联动

不包含：

- 多轨编辑
- 复杂时间轴
- 批量样式编辑

## 4. 关键规则

- 当前选中字幕必须清楚
- 播放时当前字幕行应随播放头自动切换并保持在可视区域，字幕文字内的播放光标应按当前字幕进度连续移动；进入编辑状态后使用原生闪烁光标
- 文本、入点、出点是主操作
- 插入与合并保留，但应是轻量操作
- 空字幕允许存在，用于对齐或补位
- 删除不是核心路径，不应成为主要视觉动作
- `Space` 是主操作键：播放时按下会暂停并进入编辑，编辑时按下会退出编辑并继续播放
- 播放中的字幕光标必须由当前真实播放时间驱动：有词级时间戳时按词元起止时间定位，并在词内连续插值；没有词级时间戳时按字幕区间比例估算
- 播放暂停进入编辑时，当前字幕、文本焦点和 UTF-16 光标位置必须从暂停瞬间恢复，不能默认跳到文本末尾；编辑器获得 first responder 后仍要再次确认该位置
- 中文输入法正在组词（IME marked text）时，编辑状态下的 `Space` 必须保留给输入法选词，不触发播放恢复
- 编辑状态下 `Shift + Space` 输入空格，`Esc` 退出编辑
- `Tab / Shift + Tab` 在开始时间、结束时间、字幕文本之间切换
- `J / K / L` 负责后退、暂停取时、循环调速播放
- `Command + B` 分割当前字幕：文本编辑器有光标时按光标位置分割；没有有效光标时，按当前播放头分割
- 分割只作用于当前字幕，不重新运行全局自动分段器，也不改动其他字幕
- 分割后的两条字幕必须保留原文全部字符，左条结束时间等于右条开始时间，不允许重叠或产生空白时间
- 有词级时间戳时，优先使用词元边界；没有词级时间戳时按播放头或字幕时长比例估算，并明确提示用户这是估算值
- 光标位于一个字符之后时，分割点就是该字符之后；不强制用户先切换到时间线或逐字拖动播放头
- 分割成功后选中新生成的右侧字幕，方便用户继续编辑
- `Command + Shift + Up / Down` 分别插入前一条 / 后一条，`Command + Shift + M` 合并下一条，`Command + Delete` 删除当前字幕
- 上述编辑快捷键必须通过菜单命令提供，不能抢占中文输入法组词和普通文本输入
- `Command + E` 按当前导出设置导出字幕
- 快捷键说明必须能在编辑页右侧直接查看，也必须能从全局菜单重新打开

## 5. 页面要求

- 列表可快速浏览多条字幕
- 当前条目有明确反馈
- 编辑状态与浏览状态切换自然
- 播放控制与当前时间可辅助校点
- 设置入口不侵入编辑主体
- 导出按钮应出现在编辑页顶部操作区，并复用设置中心里的导出条件
- 分割入口应同时出现在当前字幕操作区、字幕文本编辑上下文菜单和「字幕」菜单中，并显示“光标优先，播放头兜底”的规则
- 右侧检查器按“当前字幕 / 编辑操作 / 项目信息”三个同级分区组织；三个分区标题必须使用一致的字号和字重，字段标签、操作名称与项目内容使用统一的二级正文层级
- 当前字幕分区依次展示序号、开始时间、结束时间、时长和紧凑文本编辑区；编辑操作逐行展示图标、名称和分隔清楚的快捷键，完整快捷键说明固定在侧栏底部
- 右侧栏分区内使用紧凑间距；分割与删除操作保持统一黑白层级，不额外使用蓝色或红色强调
- 工作台顶部保留速度菜单，不再显示无实际功能的“预览”胶囊；导出与显示 / 隐藏右栏使用相同高度、圆角、`12 pt` 常规字重和内边距的大按钮，只通过主次配色区分
- 右栏首个分区整体下移，使“当前字幕”与顶部“隐藏右栏”按钮处于同一视觉高度；“当前字幕 / 编辑操作 / 项目信息”三个分区标题统一使用 `16 pt` 字号
- 编辑操作的快捷键标记使用 `11 pt` 字号，文本预览输入内容使用 `13 pt` 字号，保证输入与快捷操作信息清晰可读
- 完整快捷键页不显示“字幕编辑工作台”副标题；“完成”复用工作台顶部次要按钮样式；快捷键使用 `14 pt` 粗体键帽，每条说明增加纵向留白并以分隔线区分

## 6. 验收标准

- 用户可逐条修改文本、入点、出点
- 插入前后字幕后，用户能继续编辑新条目
- 合并后时间和文本结果符合预期
- 将“这是一个测试句子”把光标放在“测试”后分割，应得到“这是一个测试”和“句子”两条，字符顺序完整
- 播放头位于当前字幕内部且没有文本光标时执行 `Command + B`，应按播放头生成两条连续字幕
- 播放头不在当前字幕范围内且没有有效光标时执行分割，应不修改字幕并给出可理解提示
- 无词级时间戳的 SRT 和有词级时间戳的转写结果，都能完成分割，且不会调用全局自动分段器改写其他字幕
- `Command + B`、插入、合并、删除快捷键在文本输入和中文 IME 组词状态下不误触发；普通输入仍可正常工作
- 音频模式下可结合播放进行校准
- 播放与编辑可只靠键盘主路径完成，不依赖频繁点鼠标
- 播放过程中播放光标应随时间移动；暂停后应保留在暂停瞬间对应的字符，并立即进入可输入、可移动的原生编辑状态
- 用户能在工作台内看到精简快捷键说明，并可打开完整说明
- 完整快捷键说明中 `Tab / Shift + Tab` 不应被截断或错误换行

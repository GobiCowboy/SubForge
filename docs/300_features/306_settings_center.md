# 306 设置中心

## 1. 功能目标

把所有配置集中到独立页面处理，不让主页面和编辑页面承担配置负担。

## 2. 主要场景

- 选择转写引擎与语言（含本地 FunASR、韩语）
- 配置 AI 校对
- 调整字幕样式
- 设置导出参数
- 指定目录监听路径
- 测试当前配置可用性

## 3. 功能范围

包含：

- 转写设置
- 校对设置
- 字幕样式设置
- 导出设置
- 目录监听设置
- 可用性测试入口（内置测试音频 / 样本文本）

不包含：

- 复杂账号系统
- 多用户配置同步

## 4. 关键规则

- 设置页独立存在
- 保存后必须生效
- 可选云能力不应阻塞默认使用
- 新安装默认配置：菜单栏图标开启、界面语言简体中文、转写引擎本地 FunASR（老用户已有配置不强制改写）、识别语言中文、校对关闭、基本样式横屏内白外黑、导出格式 SRT + FCPXML、导出到 FCP 开启、自动覆盖开启、保存位置与原文件同目录、目录监听关闭
- 本地 FunASR / Whisper / Apple 语音：各自在「第一次正式转写」弹一次说明（本地适合草稿；要更准建议云端）；设置页验证不弹
- 转写结果剥句末收尾标点（保留问号/感叹号）；校对结果与导入 SRT 不剥
- 测试能力用于验证配置，不应替代正式流程验收
- 主窗口只保留轻量设置入口，不在首页和编辑页分散堆配置项
- Whisper 设置中必须能看到模型下载状态，并优先使用国内可访问镜像；**安装包默认不内置 Whisper 权重**，用户按需下载
- FunASR / SenseVoice 为推荐本地方案；设置中必须能看到运行时检测、模型与 VAD 下载状态，并优先使用国内可访问镜像
- “菜单栏图标”开关必须控制实际状态栏入口显隐，不只是保存配置
- 菜单栏图标开启时，主窗口点关闭只隐藏窗口并进入菜单栏常驻模式；正常打开和最小化时仍显示 Dock 图标，并可通过 `Command + Tab` 切回应用

## 5. 配置分组

- 转写引擎与语言
- Whisper / FunASR 模型下载与云端 ASR 参数
- 单条字幕最大字数（默认 32，注入公共分段器，统一作用于所有转写引擎的切句结果，而不是各引擎各解一次；用户修改后以用户设置为准）
- 单条字幕最大字数必须放在官方 / 自定义 / 本地三种方案共享区域，不能只在自定义和本地设置中出现
- 标点保留策略按标点组选择；未选中的标点在 AI 校对完成后替换为空格
- 热词分为逐视频热词与固定热词：逐视频热词在每次转写前输入，固定热词在通用设置中维护并可独立启用；两者合并去重后交给 AI 校对
- 热词清单严格区分大小写、空格和符号，AI 校对必须按清单中的原始写法输出，不得自动转换大小写
- AI 校对开关、服务商、Base URL、模型与提示词
- 字幕样式
- 导出格式（SRT / FCPXML / SRT + FCPXML）、输出目录、自动覆盖与导出到 FCP
- 视频创作总目录与自动监听、人工校对模式；视频创作总目录是包含多个视频项目的上级目录，监听覆盖其子目录中新导出的音频
- 通用设置（界面语言、菜单栏图标等）
- 菜单栏菜单：显示 SubForge、导入文件、开始/停止监听、导出、设置、退出，菜单项使用系统图标保持可扫读

## 6. 验收标准

- 用户能独立完成配置；文本、开关、滑块等设置修改后立即自动保存，不依赖关闭设置窗口或额外保存按钮
- 重新进入应用后配置可恢复
- 转写 / 校对 / 导出行为能反映设置结果
- 开启“导出到 FCP”后，导出流程会在生成 FCPXML 后尝试打开 Final Cut Pro 导入文件
- 开启“菜单栏图标”后状态栏出现 SubForge 入口；关闭后入口隐藏
- 菜单栏图标开启时关闭主窗口后应用继续运行，Dock 图标隐藏；从菜单栏或监听流程重新显示主窗口后，Dock 图标恢复
- “基本样式”会影响 FCPXML 导出的字幕标题样式；横屏默认字号 `56 pt`、位置 `X 0 / Y -467 / Z 0`，竖屏默认字号 `35 pt`、位置 `X 0 / Y -495 / Z 0`
- 用户手动修改字号或 X/Y/Z 后，FCPXML 导出必须使用用户设置值

- 复用 `SettingsPill`、`SettingsListSection`、`SettingsValidationState` 与现有分段配置，不新增第二套状态来源。
- “推荐 / 实验”从方案标题中拆为小型蓝色标签，方案枚举仍是唯一选择状态。
- 转写与 AI 校对页签右侧显示当前配置完整性和最近验证结果；验证结果继续由 `AppSettings` 持久化。
- 购买区只调整间距和按钮层级，不改变 StoreKit 商品、购买或刷新额度流程。
- 字幕最大字数提升到方案共享区域，并确保官方智能字幕返回结果也进入同一公共分段器。

## 8. 2026-07-19 实现与验证

- 官方 / 自定义 / 本地方案标题已拆分为主标题与蓝色小标签。
- 自定义与本地的转写 / AI 校对页签右侧已显示真实配置完整性及最近验证结果。

- 购买操作区与套餐卡片间距加大，购买按钮缩小，StoreKit 行为保持不变。
- `swift test` 通过 21 项，新增官方智能字幕公共字数限制测试。

## 9. 2026-07-23 导出默认值与首次监听引导

- 新安装的导出默认值为：`SRT + FCPXML`、导出后自动导入 Final Cut Pro、与源文件同目录、自动覆盖。
- 自动监听继续默认关闭。第一次点击导出时显示一次性引导，用户只有勾选“启用自动监听”后才会进入系统目录选择器。
- 引导与设置页统一使用“视频创作总目录”：即包含多个视频项目的上级目录；监听只处理该目录及子目录中之后新导出的音频。
- 未安装 Final Cut Pro、或当前格式不生成 FCPXML 时，仍成功完成文件导出，不将其作为导出失败。

## 10. 2026-07-23 字幕方案侧边栏

- 移除字幕页顶部的三方案卡片；官方智能字幕、自定义服务、本地识别改由设置侧边栏中的“字幕方案”分组切换。
- 当前方案以原生单选圆点与侧边栏选中背景共同表达；保留“推荐 / 实验”标签，不再额外重复方案互斥说明。
- 切换到本地识别时继续恢复用户最近使用的本地引擎。

## 11. 2026-07-23 设置层级与标题收敛

- 侧边栏将“字幕”恢复为一级标题，三种方案作为缩进子项，避免与“通用”等一级设置混淆。
- 当前字幕方案页面标题采用“字幕 - 当前方案”格式；通用、样式、导出、目录监听页面只保留一个主标题。
- 移除页面副标题和与主标题重复的分组标题，设置内容直接从配置卡片开始。

## 12. 2026-07-23 字幕方案层级调整

- 当前方案在侧边栏使用与一级设置一致的实心蓝色选中态；“推荐”使用小型蓝色标签，“实验”使用小型灰色标签。
- “转写 / AI 校对”收敛为一级文字页签，不重复显示配置与验证状态。
- 移除“转写配置 / AI 校对配置”重复标题；本地模型选择后紧接对应模型设置，单条字幕最大字数单独放在模型设置之后。
- 字幕页标题中的方案名使用较小字号；转写与 AI 校对页签后以绿色或灰色对勾仅表示配置状态。

## 13. 2026-07-26 热词与设置持久化

- 通用设置新增并统一管理：单条字幕最大字数、可选保留标点、逐视频热词开关、固定热词开关与内容、AI 校对提示词。
- 默认最大字数为 `32`；字幕标点不计入有效字数，语气词也不计入有效字数。
- 设置页通过根绑定的写入链路立即调用 `SettingsStore.save`；切换设置分类和设置窗口销毁时继续执行一次保存兜底，用户返回主页面但不关闭设置页时也不会丢失输入。
- 固定热词与逐视频热词可以独立启用；启用后合并去重并写入本次校对提示词，关闭固定热词时保留其内容但不参与当前任务。
- 热词提示词明确要求严格区分大小写、空格和符号；提示词由客户端组合后分别透传给官方智能字幕和自定义 AI 校对服务，旧客户端未提供自定义提示词时继续使用服务端原有默认提示词。
- `swift test` 已通过 58 项；本地构建和 Parallels 虚拟机均已验证，虚拟机不内置 FunASR 模型权重。

# 口播音频切分测试：中文词边界与英文短语保护

测试音频：`/Users/jago/Documents/vedio/06_subforge/Sub forge演示.mp3`

测试模型：`qwen3-asr-flash-filetrans`

测试脚本：`script/test_qwen_segment_rules.py`

## 本次新增逻辑

- 使用 macOS `NaturalLanguage` 的 `NLTagger` 获取中文词边界。
- 将字级 ASR 时间戳按词边界聚合成词块。
- 连续英文单词合并成一个英文短语块，例如 `Final Cut Pro`。
- 切分时不允许进入中文词块或英文短语块内部。
- 标点和语气词不计入有效字数。
- 少于 3 个有效字时，优先在当前 ASR segment 内向后合并。
- 不跨越 ASR segment。
- 32 个有效字仍是切分目标；如果没有合理边界，保留完整词块优先于把词语拆开。

## 统计

- ASR segment：61 个
- 规则切分结果：169 条
- 本次没有跨越 ASR segment

## 重点结果

### 中文词语没有被硬拆

这次没有再出现：

```text
下
载也可以
```

而是保持了：

```text
或者去我的 GitHub 仓库去下载也可以。
```

### 英文短语没有被拆开

```text
如果你使用 Final Cut Pro 制作非英文视频，
```

`Final Cut Pro` 保持完整，没有出现 `Final Cut` / `Pro` 这种拆法。

### ASR 识别错误仍然属于校对问题

例如本次出现：

```text
音频格式选 MP 三。
你可以看到它正确的把这个妻子修改了。
```

这里的 `MP 三`、`妻子` 不是切分器拆坏的，而是 ASR 识别结果，需要 AI 校对或专有名词词典处理。

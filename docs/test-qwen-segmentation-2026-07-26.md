# Qwen ASR 字幕切分测试

测试音频：`/Users/jago/Documents/vedio/06_subforge/Subforge.mp3`

测试模型：`qwen3-asr-flash-filetrans`

当前规则：

- 不跨越 ASR segment。
- 一级标点 `。！？!?；;，,` 直接作为切分边界。
- 顿号 `、`、冒号 `：:` 平时不主动切分。
- 一级切出的片段超过 32 个可见字符时，向前寻找最近的顿号或冒号切分。
- 最终只在片段少于 3 个可见字符时尝试向前合并。

- 第 38、39 条说明“逗号直接切分”会产生“感谢观看，”这样的短字幕；这可能需要另加“短片段合并”或调整一级标点策略。
- 所有结果都没有跨越原始 ASR segment。
